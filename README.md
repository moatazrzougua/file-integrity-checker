# File Integrity Checker

## About the Project
This is my first Python project in cybersecurity. It calculates the SHA-256 hash of a file to help identify changes in its content.

## Features
- Calculates the SHA-256 hash of a file.
- Reads files in small blocks to handle large files efficiently.
- Handles missing files with an error message.

## Technologies Used
- Python 3
- hashlib
- SHA-256

## Requirements
- Python 3 installed on your computer.

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the program:

```bash
python main.py
```

4. Enter the name or path of the file you want to check.
